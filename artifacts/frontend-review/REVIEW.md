# Frontend refinement review — 29 October 2026

Branch: `polish/frontend-mumo-refinement`.

The review used better-ui, emil-design-eng, apple-design, improve-animations, and the available portion of web-perf. Three agents independently reviewed shared UI, Mumo rendering, and motion. The motion advisor stayed read-only; the implementation agents and root applied the user-authorized fixes. Existing product composition, palette, platform typography, and Tailwind conventions were retained.

## Coverage

Inspected authentication, workspace navigation and drawers, meeting preview, meeting controls, gallery/focus layout, participant tiles, people/search/pagination, chat/composers, AI streaming/stop/retry/copy/history, settings/selects, theme changes, shared Arc controls, audio contours and frame scheduling, and both Mumo renderers. Browser scenarios cover keyboard focus, Escape during entrance, reduced motion changed at runtime, long and multilingual names, small viewports, local capture errors and resource cleanup, and WebGL failure.

Auth, workspace, and meeting screenshots cover phone and desktop in light and dark. Existing responsive checks also cover widths 320, 375, 768, 1024, 1440, and 2560. These are local development checks, not field telemetry or a claim of full browser/device coverage.

Theme recoloring and visibility restoration explicitly render the cached frame, preserving still-scene correctness. Shape morphs still rebuild their shell. Context loss releases the WebGL scene and reveals the interactive SVG fallback.

Measured browser evidence: 20 observed idle browser frames, zero shell-normal rebuilds. This is a structural-work regression check; it is not an FPS, battery, or elapsed-time benchmark. A separate E2E check verifies no scene-module request for hidden login artwork, then verifies loading when the viewport makes it visible.

```sh
pnpm verify
pnpm run doctor
pnpm --filter @unmute/frontend exec playwright test --workers=2 --reporter=list,html
```

Playwright produces an HTML report at `frontend/playwright-report/index.html`, screenshots under `frontend/test-results/`, and JSON attachments for Mumo geometry work, visibility loading, and preview session requests. The committed representative screenshots in this directory are a durable review artifact. The tests reproduce them.

The first full browser run exposed the mobile picker overlap and short audio-fixture silence; both were repaired. Repeated development preview session calls then reached the existing 60-per-minute auth limit; the unnecessary calls were removed instead of changing the limiter or disabling security checks.

Not verified: DevTools performance trace and network waterfall, 10% animation playback/frame stepping (the built-in browser's raw Animation CDP method is unsupported), physical touch-device gesture feel, Safari/Firefox, deployment/field performance, and a real Google OAuth login. Browser testing used the built-in browser and, after explicit user permission, isolated Playwright Chromium. No personal Chrome profile was inspected.

Verdict: Approve for the inspected and verified flows, subject to the explicitly unverified coverage above. No confirmed HIGH finding from this audit remains open.
